O que é o projeto: Uma ferramenta de automação backend que sincroniza contratos fechados (Closed Won) do HubSpot e dispara rotinas inteligentes de cobrança utilizando IA (OpenAI).

Tecnologias usadas: Python 🐍, HubSpot API, OpenAI API, Pandas/Ruff, Pydantic, Python-Dotenv.

Como executar: Instruções rápidas de instalação de dependências (pip install -r requirements.txt) e como configurar o .env.
